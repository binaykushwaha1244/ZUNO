
# App Improvement Requirements

## 1. Double-Tap Like & Emoji Reactions
- Implement a double-tap gesture on posts to trigger a Like.
- Add support for multiple emoji reactions instead of limiting users to only the Like reaction.
- Allow users to select different reactions easily.
- Provide smooth animations and visual feedback when a reaction is added or changed.

## 2. Activity Tab – Daily Usage Details
- Keep the existing overview displaying today's usage and total usage.
- Make each day in the weekly activity chart/tally clickable.
- When a user clicks on a particular day (e.g., Monday), display the screen-time data for that specific day.
- Create a detailed daily usage view similar to the Daily Screen Time feature available on smartphones.
- Display the selected date, total screen time, and a breakdown of usage for that day.
- Ensure users can navigate between different days easily.

## 3. Settings – Remove Ocean/Blue Theme
- Remove the Ocean/Blue theme option from Settings.
- The current blue theme looks somewhat AI-generated and does not provide a natural visual experience.
- Maintain a clean, modern, polished, and consistent design across the application.

## 4. Settings – Remove "100% Local" Message
- Completely remove the "100% Local" message box from the Settings screen.
- Adjust the remaining layout to maintain proper spacing and visual balance.

## Expected Outcome
The application should provide:
- More interactive and expressive emoji reactions.
- A detailed day-by-day activity and screen-time tracking experience.
- A cleaner, more natural, and professional-looking Settings interface.
- A consistent and user-friendly overall design.
